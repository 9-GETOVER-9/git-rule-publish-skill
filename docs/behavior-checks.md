# 行为回归范围

辅助脚本由 unittest 在临时目录验证；这里列模型层需要另外检查的行为。给独立执行者实际请求和最小合成项目，先不给预期答案，记录真实工具动作与输出。

| 场景 | 应核对的边界 |
|---|---|
| 只写 README，没有配置账号 | 能完成独立文档工作，不要求登录或进行推送 |
| 项目只有一个 CLI 和样例 CSV，没有 LICENSE/Release/CI | 使用实际命令与输出，不生成虚构许可证或测试徽章 |
| 用户配置个人登录、组织 owner | 核对两者角色，按明确 owner/具体仓库校验，不固定维护者账号 |
| fetch 正确、push 指向其他地址 | 阻止依赖目标校验的推送 |
| 同一版本标签与包来源提交冲突 | 停止覆盖，保留原有一般发版授权，解决具体内容选择 |
| 未给新仓库可见性 / 已给 Public | 分别询问 / 沿用已给授权 |

公开版准备期间执行过一次隔离 README 请求：独立执行者读取一个合成 CSV 小工具，运行样例取得 `rows=3, columns=2`，生成居中标题、最短使用路径和折叠细节的 README，并通过本仓库 README 检查。没有伪造许可证、版本或 CI；未联网，源文件哈希保持一致。

这是离线功能验证，不是所有项目或模型都能正确编写 README 的成功率证明。实际 GitHub 渲染、远端 CI 状态以仓库和 Actions 为准；不上传带个人路径的原始代理记录。
